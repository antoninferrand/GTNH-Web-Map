# Geometric patch intersection capacity

Custom atlas models can have many more geometric patches than texture slots: the node linker has 1,460 patches with 256 slots, and the Witching Gadgets terraformer has 846 patches with 16 slots. `IsoHDPerspective.OurPerspectiveState` initially allocated its five parallel intersection buffers from `HDBlockModels.getMaxPatchCount()`. For custom renderers that value comes from the maximum texture count. A ray intersecting enough geometry could therefore overflow the buffers while writing hits.

Before processing a mesh, the perspective state now grows every intersection buffer to the actual patch-array length. Each patch contributes at most one intersection. The buffers remain local to that raytracing state and are reused for later meshes that fit. Sorting, texture indices, UV values, normals and shader completion behavior are unchanged.

`tools/test-patch-capacity.py` compiles the complete production `IsoHDPerspective` and invokes its actual private patch-intersection path through reflection. It uses 2,048 and then 3,072 coincident, intersectable patches sharing only 16 texture slots. The test verifies all hits, all five buffer capacities, shader order, UV coordinates, normals, early shader completion, state restoration, allocation reuse, an empty mesh and independence from a second perspective state. It passes 20,532 assertions. A negative control with the new capacity call removed reproduces `ArrayIndexOutOfBoundsException: Index 16 out of bounds for length 16` in production `handlePatches`.

For local execution, generate reproducible compile/runtime classpaths using `tools/render-test-classpaths.gradle`, then run `python3 tools/test-patch-capacity.py --compile-classpath build/render-tests/compile-classpath.txt --runtime-classpath build/render-tests/runtime-classpath.txt`. The default classes path is `build/classes/java/main`; `--classes` can instead name the unshaded `*-dev-preshadow.jar` when a build has removed its intermediate class directory. A shaded dev artifact is unsuitable because it changes JSON API package names.
